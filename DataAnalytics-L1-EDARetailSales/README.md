# Task 1: Exploratory Data Analysis (EDA) - Retail Sales

## 📌 Project Overview
This project performs a comprehensive Exploratory Data Analysis (EDA) on a Retail Sales Dataset to identify purchasing trends, analyze customer demographics, and evaluate overall product performance.

## 🛠️ Tech Stack
- Language: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn

## 🔍 Key Deliverables & Analytical Steps
1. Data Cleaning & Preprocessing: Checked missing values, dataset shape, and correct data types.
2. Descriptive Statistics: Computed mean, median, mode, and standard deviation for key metric columns (Age, Quantity, Price per Unit, Total Amount).
3. Time Series Analysis: Extracted monthly and quarterly trends to highlight sales variations over time.
4. Customer & Product Insights: Analyzed spending patterns across gender demographics and product categories (Clothing, Electronics, Beauty).
5. Data Visualization: Plotted bar graphs, pie charts, and distribution plots to present findings clearly.

## 📁 Repository Structure
- Task1_EDA.ipynb: Full Jupyter Notebook containing EDA code, commentary, and charts.
