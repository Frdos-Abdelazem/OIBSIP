# Task 2: Customer Segmentation Analysis

## Overview
Applying K-Means Clustering and RFM Analysis (Recency, Frequency, Monetary) to segment customers into targeted profiles.

## Tech Stack
- Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn)

## Results & Deliverables
- Optimal K: Determined $K = 3$ using the Elbow Method.
- Clusters Identified:
  - Cluster 0 (VIPs): High spend & frequency.
  - Cluster 1 (At-Risk): High recency, lower frequency.
  - Cluster 2 (Occasional): Low to moderate expenditure.
